Configuración del centro

Datos que aparecen en reportes y notificaciones

Sistema de gestión de citas médicas para centros de salud. Automatiza el agendamiento, evita cruces de horario, notifica a pacientes y médicos y centraliza pagos y reportes.

Versión 1.0
Objetivo

Gestionar de forma eficiente el agendamiento de citas, reduciendo los errores de la gestión manual.

Cuatro roles

Paciente, Médico, Recepcionista y Administrador, cada uno con las funciones de su perfil.

Tecnologías

Python (Flask), MySQL 8, HTML5, CSS3, JavaScript y Bootstrap 5.
